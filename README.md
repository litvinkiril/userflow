# UserFlow 📚

**Система управления студенческими работами с проверкой на плагиат**

## Спецификация
https://litvinkiril.github.io/userflow/

## ✨ Особенности

✅ **Полный цикл управления работами** - от загрузки до анализа плагиата  
✅ **Микросервисная архитектура** - масштабируемость и независимое развертывание  
✅ **S3-совместимое хранилище** - надежное хранение файлов  
✅ **Асинхронная обработка** - неблокирующий анализ плагиата  
✅ **Полная документация** - Swagger UI и архитектурная документация  
✅ **Контейнеризация** - легкий деплой через Docker Compose  

## 🏗️ Архитектура

### Микросервисы

| Сервис | Порт | Назначение | Статус |
|--------|------|------------|---------|
| **Gateway API** | 8080 | Единая точка входа, маршрутизация | ✅ Реализован |
| **File Storage Service** | 9090 | Управление файлами, работа с S3 | ✅ Реализован |
| **File Analysis Service** | 9091 | Анализ работ на плагиат | ✅ Реализован |
| **PostgreSQL** | 5432 | Основная база данных | ✅ Реализован |
| **MinIO** | 9000/9001 | S3-совместимое хранилище файлов | ✅ Реализован |

### Технологии

**Бэкенд:**
- Java 21 + Spring Boot 3
- Spring Web, Spring Data JPA, Spring Validation
- SpringDoc OpenAPI 3 (Swagger UI)

**Базы данных:**
- PostgreSQL 15 (основная БД)
- H2 Database (для тестирования)

**Хранилище:**
- MinIO (S3-совместимое объектное хранилище)

**Контейнеризация:**
- Docker
- Docker Compose
